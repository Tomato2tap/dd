CODE TOPAZE
Code topaze - Structure privilegiée
La structure privilégiée d’un client est la structure d’affectation du client. Un conseiller de cette caisse lui est alors rattaché. La structure privilégiée peut être différente de la structure gestionnaire (propre à chaque contrat) dès lors que le client possède des contrats dans plus d'une caisse. Elle est déterminée par un algorithme. Cette notion n’est valable que pour le périmètre ARKÉA. Dans les autres cas, BtoB par exemple, la valeur est indiquée par défaut. Dans la table T7GLPST (table des liens personne structure) de Topaze Structure, elle est identifiée par l’indicateur IDC-STR-PVL = ‘0’.
