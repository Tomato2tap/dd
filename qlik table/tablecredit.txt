53
CODE TYPE FRANCHISE
Type de franchise (ex : 0 = pas de franchise, 2 = normale amortissement différé )
La franchise est une période inclue dans le déroulement du prêt qui va du 1er déblocage jusqu’à la 1ère échéance de remboursement de capital. Sa durée est incluse dans la durée totale du prêt et est figée dans l’offre de prêt. Durant cette période, l'emprunteur ne rembourse pas de capital. Il existe plusieurs types de franchise : - la franchise normale est une période durant laquelle l’emprunteur paye les intérêts sur les sommes débloquées - la franchise totale est une période durant laquelle l'emprunteur ne paye pas d'intérêt. Les intérêts non payés (reportés) sont stockés et prélevés en phase de remboursement.
